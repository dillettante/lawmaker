# ch64: 전문용어
**원문**: 정비기준 p.46–55

## 핵심
전문 분야 용어라도 일반 국민이 쓰거나 쓸 가능성이 있으면, 일상에서 널리 쓰이는 쉬운 우리말로 대체하거나 뜻풀이·원어를 병기하여 알기 쉽게 고친다.

## 기준·규칙
- **전문용어 뜻과 정비 근거**: 전문용어는 특정 분야에서 주로 쓰는 용어로 어려운 한자어·외국어가 많다. 「국어기본법」 제14조제1항(공문서는 쉬운 용어·문장으로)·제17조(전문용어 표준화)에 따라, 일반 국민 대상 용어는 쉽게 고쳐 쓴다. (원문 근거: p.46)
- **원칙 ① 개념 명료화**: 순화안은 대상 용어의 개념을 분명·간결하게 드러내 대체어만 보고도 의미를 파악할 수 있게 한다. (원문 근거: p.46)
- **원칙 ② 우리말 우선**: 우리말 대체를 제일 먼저 고려하되, 일상에서 널리 쓰이는 친숙하고 쉬운 용어로 한다. (원문 근거: p.46)
- **원칙 ③ 뜻풀이 병기**: 적절한 우리말 대체어가 없으면 괄호로 뜻풀이를 덧붙여 정비할 수 있다. (원문 근거: p.46)
- **원칙 ④ 병기 위치**: 설명·영문 등 원어 병기는 해당 용어가 맨 처음 나오는 곳에서 한 번만 하고, 원어는 외래어 표기법에 따라 쓴다. (원문 근거: p.46)
- **원칙 ⑤ 눈높이**: 의무교육(중학교 졸업) 수준 어휘가 바람직하나, 어려우면 고등학교 교육 수준 범위에서 쓸 수 있다(무리한 순화는 하지 않음). (원문 근거: p.46)
- **정비 유형 1) 쉬운 말 대체**: 대응하는 쉬운 우리말이 있으면 원래 형태와 무관하게 대체 — 응결수→물방울, 탤컴→면도용 파우더. (원문 근거: p.47)
- **정비 유형 2) 대체+원어 괄호 병기**: 쉬운 말로 대체하되 원어를 괄호에 병기 — 드레싱→소독(dressing), 전굴→앞굽히기[前屈]. (원문 근거: p.47)
- **정비 유형 3) 대상 용어 유지+쉬운 말 괄호**: 사용 빈도가 높거나 혼선 우려로 바로 대체가 곤란하면 원용어를 쓰고 괄호에 쉬운 말 — 집수정→집수정(물저장고), 스웨이징(Swaging)→스웨이징(압축가공). (원문 근거: p.48)
- **정비 유형 4) 원어 병기+설명 추가**: 대체할 쉬운 말이 없고 원어가 이해에 도움되면 괄호에 한자·원어를 병기하고 설명을 덧붙인다. (원문 근거: p.49)
- **정비 유형 5) 문장으로 풀어 쓰기**: 문장으로 풀어 쓰는 것이 더 알기 쉬우면 그렇게 한다 — 절연상태→전기 또는 열이 통하지 않는 상태. (원문 근거: p.50)

## 분야별 전문용어 정비 목록 (활용 안내)
- **분야별 전문용어 정비 목록** (원문 p.52~): 건설·경제/경영·공업/공학·교통·기계·농업/축산/산림 등 분야별로 [대상용어 → 정비안] 표를 제공. 정비안은 대체어 또는 원용어+괄호 뜻풀이 형태로 구성된다(예: 소단→소단(小段: …), 인터체인지(IC)→나들목(IC)). 특정 분야 전문용어 정비 시 대조표로 참조 — 전체 목록은 원문 p.52 이하를 직접 확인(여기서는 존재·구성만 안내). (원문 근거: p.52)

## 주의·함정
- **무리한 순화 금지**: 일상 관련성이 낮은 순수 전문용어까지 억지로 우리말화하지 않는다. 눈높이는 중졸→고졸 순으로 넓힌다. (원문 근거: p.46)
- **혼선 우려 시 원용어 유지**: 사용 빈도가 높거나 대체 시 혼선이 생기면 원용어를 쓰고 괄호로 보완(유형3). (원문 근거: p.48)
- **원어 병기는 처음 한 번만**: 반복 병기하지 말고 최초 등장 위치에서만 병기한다. (원문 근거: p.46)
- **목록은 대조용**: 분야별 목록은 참조표이며, 실제 정비안은 개별 법령 맥락으로 확정한다. (원문 근거: p.52)

## 요점
1. 전문용어라도 일반 국민 대상이면 쉬운 말로 고친다(국어기본법 §14·§17). (p.46)
2. 우리말 대체 → 대체+원어 병기 → 원용어+쉬운 말 괄호 → 원어 병기+설명 → 문장 풀어쓰기의 5유형을 단계적으로 적용한다. (p.47–50)
3. 대체어만으로 개념이 드러나야 하며, 원어 병기는 최초 1회·표기법 준수. (p.46)
4. 분야별 정비 목록(p.52)은 분야 전문용어 정비 시 대조표로 활용한다. (p.52)
