# ch02: 입법의 필요성 판단과 입법 형식의 선택 (체계정당성·제정개정·통폐합·분법)

**원문**: 입안심사기준 p.8–17

## 핵심
입법 필요성이 인정된 뒤에는 법령 형식을 선택하는데, 체계 정당성 원리를 준수하면서 제정이냐 개정이냐(특별법 문제 포함), 통폐합이냐 분법이냐, 어느 법령 형식(법률/대통령령/총리령·부령)에 어떤 내용을 담느냐를 판단한다.

## 기준·규칙
- **입법 필요성 판단(법률유보)**: 행정지도·예산조치로 족하면 입법 불요. 판단 기준은 주로 법률유보(중요사항유보설=본질성론): 행정의 본질적·중요한 사항(국민 권리·의무 등, 급부행정의 국가·사회적 중요사항 포함)은 법률에 근거를 둔다.
  - 적용: 입법 착수 여부 결정
  - 원문 근거: p.8
- **과잉입법 경계**: 입법 불요 사항을 굳이 입법하면 과잉입법 문제 발생. 법령의 경직성(개폐 전까지 유효 존속)을 고려해 필요성을 면밀히 검토.
  - 원문 근거: p.8
- **체계 정당성 원리**: 동일·상이 규범 간 구조·내용·근거 원칙이 상호 배치·모순되어서는 안 된다는 헌법적 원리. 위반만으로 곧 위헌·위법은 아니고, 결과적으로 비례·평등 원칙 위반이 되어야 위헌 문제 발생. 「행정기본법」 제38조제2항제2호도 명시.
  - 원문 근거: p.10–11
- **제정 vs 개정 기준**: 유사분야 법령 개정으로 쉽게 반영되면 개정, 전혀 새로운 분야이거나 여러 법령 사항을 체계적·종합적으로 규율할 필요가 있으면 제정. 입법경제·법체계 정합성·국민 이해도 종합 고려.
  - 원문 근거: p.10–11
- **특별법 신중론**: 특별법 양산은 체계 정당성 침해·형평 문제 초래. 일반법 체계를 크게 훼손하지 않으면 일반법에 함께 규정하는 것이 바람직. 부득이 제정 시 목적 규정에 특례 대상을 명시하고, 흡수 개정을 우선 검토.
  - 원문 근거: p.11
- **통폐합 기준(5가지)**: ① 유사분야·유사내용을 여러 법령으로 분산, ② 연관성 높고 통합대상 조문 수가 적음, ③ 같은 대상자에 대해 내용별로 분산, ④ 같거나 유사한 분야인데 세부내용을 별도 법령으로, ⑤ 하나의 법률에 다수 하위법령 → 하나의 법률의 위임사항은 가급적 하나의 하위법령으로.
  - 원문 근거: p.12–13
- **분법 기준**: 방대·이질적 내용을 하나로 규정해 이해·집행이 어려운 경우 분법. 유사·관련 내용·분야·기능 기준으로, 지나친 세분 지양, 체계 정합성 유지.
  - 원문 근거: p.14
- **법령 형식별 규정 내용**: 헌법이 법률로 정하도록 한 사항·중요사항은 법률로. 대통령령은 국무회의 의결(헌법 제89조제3호)을 거치는 격에서 총리령·부령보다 중요사항을 담음. 실체적·권리의무 위임사항은 가급적 대통령령, 절차·서식(집행명령)은 총리령·부령.
  - 원문 근거: p.15–16
- **재기재 금지**: 상위법령 내용을 하위법령에 재기재하면 상위법 개폐 시 정비 누락으로 효력 다툼 발생 → 재기재하지 않는다(법제처 2011. 3. 3. 11-0068 해석례).
  - 원문 근거: p.16

### 소관 사항 예시(원문 표 재현)
| 법령 형식 | 소관 사항 예시 |
|---|---|
| 법률 | 헌법에서 법률로 정하도록 한 사항 / 국민의 권리·의무에 관한 사항 |
| 대통령령 | 법률 위임사항 / 법률 집행에 필요한 사항 / 국정의 통일적 추진·집행 기본방침 / 여러 부처 공통·국무회의 논의 필요사항 / 행정기관 조직 / 권한 위임·위탁 |
| 총리령·부령 | 법률·대통령령 위임사항 / 법률·대통령령 집행 필요사항 / 각 부처 단독 수행 사항 / 서식 / 절차적·기술적 사항 |
(원문 근거: p.16)

## 주의·함정
- **특별법 남발**: 국민여론·정치적 이유로 급히 제정된 특별법은 합리성 결여·처분적 내용으로 형평 문제를 낳을 수 있다. (원문 근거: p.11)
- **하나의 법률에 다수 하위법령**: 위임사항 소재 파악이 어렵고 법령 관계가 복잡해짐 → 원칙적으로 시행령 1건·시행규칙 1건. (원문 근거: p.13)

## 요점
1. 입법 필요성은 법률유보(중요사항유보설)로 판단하되 과잉입법을 경계한다. (p.8)
2. 체계 정당성은 그 자체로 위헌은 아니나, 비례·평등 위반으로 이어지면 위헌이 된다 — 신법 제정 시 기존 법령과의 조화를 늘 검토. (p.10–11)
3. 특별법은 최후수단 — 일반법 통합을 우선 검토하고 부득이하면 목적 규정에 특례 대상 명시. (p.11)
4. 통폐합 5기준·분법 기준을 실무 체크리스트로 사용한다. (p.12–14)
5. 권리·의무 실체사항은 대통령령, 절차·서식은 총리령·부령. 상위법령 내용은 하위법령에 재기재하지 않는다. (p.15–16)
